# 山梨クマ目撃マップ（市町村別）

山梨県在住の保護者が、県内のクマ目撃データを使って、市町村と期間を選び、目撃地点と件数・日付・状況を地図で確認できるアプリです。

朝夕の送り迎えや散歩のルート上に、最近クマの目撃があったかを地図で確認する手段がない、という困りごとに向けて作りました。

このリポジトリは、もくもく会用のテンプレート`simple-agent-template-mvp-first`から作りました。付属していた架空サンプル（おでかけ候補ファインダー）は、このアプリとは無関係です。

## できること

1. サイドバーで期間（直近7日／直近30日／今季／すべて）を選ぶ
2. サイドバーで市町村を選ぶ。件数が併記されている
3. 地図にピンが出る。密集した地点はまとまり、押すと開く
4. ピンの色が目撃からの経過を表す。凡例はサイドバーにある
5. ピンを押すと、日時・市町村・場所・状況・人身被害・出典が読める
6. 地図の右上に、表示中の目撃が**日付の新しい順**で一覧表示される
7. 一覧の行を押すと、その地点へ寄って吹き出しが開く

## 動かし方

Windows（PowerShell）:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

ブラウザが自動で開かない場合は`http://localhost:8501`を開きます。ポート8501が使用中のときは`--server.port 8511`のように別のポートを指定します。

## 画面の使い方

- **拡大縮小**は地図右下の`+` `−`かダブルクリックで行います。マウスホイールでは動きません。ホイールだと一度に何段も動いてしまうため、意図的に切ってあります
- **「山梨全体へ戻る」**（地図右下）で県全体の表示に戻ります
- **「絞り込みを解除」**（サイドバー）で期間と市町村を初期状態に戻します
- 地図の左上のチップに、いま何で絞り込んでいるかが出ます
- **目撃の一覧**は地図の右上にあります。見出し（「目撃 ◯件」）を押すと開閉します
  - 行を押すと、その地点まで地図が寄って吹き出しが開きます。まとまっているピンも展開されます
  - 並びは日付の新しい順で固定です。並べ替えの切り替えはありません
  - 地図の幅が767px以下のときは、地図が隠れないよう**閉じた状態**で開きます
  - キーボードでも操作できます。`Tab`で行を移動し、`Enter`で開きます

## 使っているデータ

- データ名: ツキノワグマ出没・目撃情報（令和8年度／直近1か月）
- 提供者: 山梨県 森林環境部 自然共生推進課
- 取得元: [やまなしデータプラットフォーム](https://catalog.dataplatform-yamanashi.jp/dataset/kuma1)
- 利用条件: [山梨県オープンデータ利用規約](https://www.pref.yamanashi.jp/opendata/kiyaku.html)（CC BY 4.0互換）
- 取得日: `data/fetched_at.txt`に記録。画面下の出所表示に出ます
- 件数と収録期間: **日々変わります。**画面のサイドバーで確認してください

列の意味、欠損や表記ゆれの扱いは`DATA.md`に書いてあります。

**このアプリは山梨県が作成したものではありません。** 規約に従い、画面には出典と「加工して作成」した旨を表示しています。

## ピンの色の意味

色は**目撃からの経過**を表します。**危険度ではありません。**

| 色 | 意味 |
|---|---|
| terracotta `#D95D39` | 0〜3日前 |
| 山吹 `#BA7E24` | 4〜14日前 |
| 苔緑 `#6F8065` | 15〜30日前 |
| slate `#69727D` | 31日前より古い |

件数はサイドバーの凡例に出ます。

経過日数は**データの中でいちばん新しい目撃日**から数えています。今日からではありません。データを更新しないまま日が経つと、すべての目撃が「古い」側へ寄ってしまうためです。

色が見分けにくい場合でも、凡例・ツールチップ・吹き出しの3か所に**言葉**でも出しています。

## このアプリで分からないこと

安全のため、できないことをはっきりさせておきます。

- **地図上の位置は目安です。** 元データの`注意事項`列に「目撃地点の大まかな付近を表示した目安」と明記されています。通学路の何メートル横か、という精度の判断には使えません
- **座標がない目撃は地図に出せません。** 推測で座標を補うことはしていません。該当があるときはサイドバーに件数を出します
- **危険度の判定はしません。** データに書かれていないことは表示しません
- **リアルタイムではありません。** 取り直した時点のデータです。取得日は画面下に出ています
- **吹き出しの「状況」は県の記述をそのまま載せています。** 個人や世帯を特定する目的で使わないでください

| **画面下（常時表示）** | 出典・利用条件・「山梨県が作成したものではありません」 |
| **「この地図について」** | 上の詳しい版、**プライバシー**、**連絡先** |

**連絡先は`app.py`の`CONTACT_URL`で設定します。** 空のときは画面に「現在は未設定」と出ます。

## データを取り直す

手元で取り直すとき:

```powershell
.venv\Scripts\python scripts\fetch_data.py
```

差し替える前に、取れたデータが読めるかを確かめます。**空でない／UTF-8で読める／必須列がそろう／目撃が1件以上ある／地図に出せる座標が1件以上ある**。ひとつでも欠けたら差し替えず、**今あるファイルを残して終了コード1**で終わります。県のサイトが一時的に落ちた日に、空の中身で上書きしてしまわないためです。

2つとも確認できてから差し替えます。片方だけ新しい状態にはなりません。

取得日は`data/fetched_at.txt`に書かれ、画面下の出所表示に出ます。

## 毎日の自動更新（公開したときだけ動きます）

`.github/workflows/update-data.yml`が、**日本時間の朝6時**に取り直します。

```text
取得 → 依存のインストール → テスト → 変更があればコミット
```

テストが落ちたらコミットしません。おかしなデータをそのまま画面へ出さないためです。

**このワークフローはGitHubへ置くまで動きません。** まだ公開していない場合、このファイルは置いてあるだけです。

### 知っておくこと

- **データが変わらない日もコミットが入ります。** 取得日を毎回書き直すためです。履歴はにぎやかになりますが、**目撃が60日間増えなくても定期実行が止まりません**（GitHubは60日間活動のないpublicリポジトリの定期実行を自動で止めます。クマの目撃は冬季に途絶えることがあります）
- 止まってしまったときは、GitHubの**Actionsタブから手動実行**すれば再開します
- 時刻はUTCで書きます。`0 21 * * *`が日本時間の朝6時です

## 公開するときの手順

**このリポジトリはまだ公開していません。** 公開する場合は次の順で行います。

1. **判断する** — 下の「公開する前に決めること」を読む
2. GitHubにリポジトリを作り、`git push`する
3. **連絡先を設定する** — `app.py`の`CONTACT_URL`に、作ったリポジトリのIssuesのURLを入れてコミットする

   ```python
   CONTACT_URL = "https://github.com/あなたの名前/リポジトリ名/issues"
   ```

   **ここが空のままだと、画面の連絡先に「現在は未設定」と出ます。** 誤りの指摘や掲載内容の相談を受け取れないまま公開することになるため、先に入れてください。
4. Actionsタブで`データを毎日更新する`を**手動実行**し、成功することを確かめる
5. [share.streamlit.io](https://share.streamlit.io/) でこのリポジトリと`app.py`を指定してデプロイする
6. 公開されたURLで、次が見えることを確かめる
   - 地図の下の**「ご利用にあたって」**（免責の4項目）
   - **出所表示・利用条件・「山梨県が作成したものではありません」**
   - 「この地図について」の**プライバシー**と**連絡先**。連絡先が**「現在は未設定」になっていない**こと

### 公開する前に決めること

- **リポジトリをpublicにしてよいか** — GitHub ActionsとStreamlit Community Cloudの無料枠の前提です
- **`状況`欄の記述を自分のURLで配信してよいか** — 地内名・市道番号・自宅の方角を含む記述があり、世帯が絞られうるものがあります。山梨県が公開しているデータですが、**配信元があなたに変わります**
- **削除依頼が来たときにどうするか** — 特定の目撃だけを除外する機能はありません。今できるのは「山梨県へ案内する」「アプリを一時的に止める」のどちらかです。元データが直れば、毎日の更新で自動的に反映されます

調査した事実として、`状況`欄の記述は**山梨県自身もPDFで公開しています**（[県のページ](https://www.pref.yamanashi.jp/shizen/kuma2.html)の令和8年度目撃情報）。県のPDFでは長い記述が表の枠で切れており、切れている部分（市道番号など）はCSVにのみあります。県は出没マップも公開しています。

### うまくいかないとき

- **pushが失敗する** — 既定ブランチが`main`か、ブランチ保護がかかっていないかを確認します
- **Actionsがコミットできない** — リポジトリの Settings → Actions → Workflow permissions が`Read and write`になっているか確認します

## 公開をやめるときの手順

1. Streamlit Community Cloud のアプリを削除する（URLが閉じます）
2. GitHubの Actions タブで`データを毎日更新する`を**Disable**する（県のサイトへのアクセスが止まります）
3. 必要ならリポジトリをprivateにする、または削除する

**2を忘れると、アプリを消したあとも毎日県のサイトへアクセスし続けます。**

**1. 誰の困りごとか（10秒）**

> 山梨に住んでいて、子どもの通学路が心配な保護者です。自治体のお知らせやSNSに情報は出るけれど、「自分の市町村で最近どこに出たか」を地図で見る手段がありませんでした。

**2. 使ったデータと出所（10秒）**

> （画面を見せながら）市町村を選びます。「身延町」を選ぶと、地図がその地域にちょうど収まるまで寄って、目撃地点だけがピンで出ます。件数は左に出ています。
> ピンを押すと、日時・場所・そのときのクマの様子・人身被害の有無が読めます。

> 右上に、表示中の目撃が新しい順で並んでいます。行を押すと、その地点まで地図が動いて吹き出しが開きます。地図から探さなくても、日付順にたどれます。

> ピンの色は目撃からの経過です。危険度ではありません。色が見分けにくくても、凡例・一覧・ツールチップに言葉でも出しています。

> 位置は県の注記どおり「おおよその目安」なので、通学路の何メートル横か、という精度では使えません。毎日の自動更新は用意してありますが、まだ公開していないので動いていません。

## 見た目を直すときの注意

### 1. CSSの入れ先が2つある

- **ページ側** — `ui_styles.PAGE_STYLES` を `st.markdown(..., unsafe_allow_html=True)` で入れる
- **地図の中** — `ui_styles.MAP_STYLES` を地図オブジェクトのヘッダーへ入れる

`st_folium`は地図をiframeに描くため、**ページ側のCSSはLeafletのPopupやズームボタンには届きません。**

### 2. 地図に足すJavaScriptは、地図の子要素にする

`st_folium`は地図のHTMLをそのまま画面へ渡しません。**地図オブジェクトの子要素をたどってJavaScriptを組み立て直します。**

そのため、次のように書いても画面には出ません。

```python
bear_map.get_root().script.add_child(folium.Element("<script>...</script>"))  # 届かない
```

`folium.MacroElement`を継承して、地図の子要素として足します（`map_overlays.py`）。

```python
bear_map.add_child(SightingListControl(...))  # 届く
```

一度この違いを見落とし、一覧・チップ・戻るボタンが**画面に出ないまま完成扱いになりました**。
`folium`の`_repr_html_()`をファイルへ書き出すと入っているので、それだけでは確認になりません。
`tests/test_streamlit_render.py`が、画面に届いているかを確かめます。

### 3. 地図の中では、変数名で他の部品を参照しない

`streamlit-folium`は変数名を付け替えます。マーカーを`marker_abc`のような名前で参照すると合わなくなります。

- 地図は`{{ this._parent.get_name() }}`で参照する
- マーカーは`dataIndex`という値を持たせ、実行時に`cluster.getLayers()`から探す
- クラスタは`map.eachLayer`で`zoomToShowLayer`を持つ層を探す

### 4. 色は1か所に書く

色や余白の値は`ui_styles.py`の定数だけに書きます。マーカーの色と凡例の色がずれないようにするためです。
`.streamlit/config.toml`のテーマ色も同じ値にします。ずれるとテーマ次第で文字が読めなくなります。

## 大切なルール

- `data/sample.csv`と`tests/data/`は架空データです。公式オープンデータとして扱いません
- 実データの利用条件と出所は、人間が元サイトで確認しています（2026年8月7日）
- 件数や日付をREADMEや`DATA.md`へ書き写しません。毎日変わるため、書いた瞬間から古くなります
